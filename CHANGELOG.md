# Changelog

## [1.0.0] - 2026-06-08
### Added
- Initial F1 timing app release
- Live timing data display with real-time updates
- Driver position tracking with sector colors (purple/green/yellow)
- Session schedule management with qualifying/race/practice types
- WebSocket connection with exponential backoff reconnection
- Mock data source for development and preview
- Widget extension for home screen
- Live Activity support for lock screen
- Dark mode optimized UI with F1 brand colors
- Settings view with configuration options
